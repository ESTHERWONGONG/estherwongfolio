# Cinematic Scroll Demo

Open `index.html` through a local static server.

Replace these files with your uploaded artwork:

- `assets/images/lake1.png`
- `assets/images/star.png`
- `assets/images/extra-stars.png`
- `assets/images/boat.png`
- `assets/images/001.svg`
- `assets/images/002.svg`
- `assets/images/003.svg`
- `assets/videos/hero-video.mp4`

The page references those exact paths. Once the files are replaced, the website will use your assets.

No browser automation is required. Open the page and control all scrolling, clicking, hover, modal, and debug-panel interactions yourself.
